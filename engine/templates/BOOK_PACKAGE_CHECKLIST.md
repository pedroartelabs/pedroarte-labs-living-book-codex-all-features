# BOOK_PACKAGE checklist

- [ ] Book title, author, language, genre and chapter count defined.
- [ ] Exact chapter titles cover `1..chapter_count`.
- [ ] Writing waves cover every chapter exactly once and in order.
- [ ] Creative brief captures heart, reader experience and exclusions.
- [ ] Book constitution contains the full literary contract.
- [ ] Immutable rules contain only rules that truly block contradiction.
- [ ] Protected scenes list scenes that require independent audit.
- [ ] Genre-specific guardians exist only in the book package.
- [ ] World/phenomenon specialists exist only when needed.
- [ ] Visual profile defines the book's image biome.
- [ ] Sound profile names the acoustic organism or environment.
- [ ] Quality profile reflects the specific risks of the work.
- [ ] Custom validators are deterministic where possible.
- [ ] `validate-book` passes.
- [ ] `compose` passes.
- [ ] `smoke-test` passes.
