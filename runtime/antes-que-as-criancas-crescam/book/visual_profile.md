# Visual profile

Cinematic naturalism. Images should feel like memories rather than advertising.

Use soft natural light, lived-in interiors, ordinary clothes, domestic imperfections and observational framing. Prefer moments between events: hands, feet outside blankets, forgotten toys, height marks, small backpacks, a child cup near an adult mug, a hand supporting a sleeping child.

No stock-photo happiness. No commercial smiles. No artificial perfection.
