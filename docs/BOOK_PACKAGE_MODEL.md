# Book Package Model

A book package answers six questions:

1. What is this book trying to make the reader experience?
2. What is canon and what can never be violated?
3. Who are the characters and what world rules exist?
4. What does each chapter do?
5. What specialists and genre guardians are unique to this work?
6. Which scenes, motifs or revelations are important enough to receive protected audits?

Everything else belongs to the engine.
