# Migration from per-book Super Prompts

Old model:

`one giant Codex prompt = creative DNA + orchestration + agent architecture + delivery pipeline`

v1 model:

`ENGINE + BOOK_PACKAGE = RUNTIME`

For a new work, the long creative discussion becomes `CREATIVE_BRIEF.md` and `BOOK_CONSTITUTION.md`. The chapter plan becomes `chapter_architecture.yaml`. Special risks become `immutable_rules.yaml`, `quality_profile.yaml`, genre guards and protected scenes.

The engine does not need to be rewritten.
