# Book package: Motor de Livros Vivos

Book-specific DNA only. This package is a deliberate stress test of the
engine's genericity: a non-fiction, meta book about the engine itself,
running on a machinery designed primarily for fiction (canon, character
bible, protected scenes). Where a fiction-oriented concept was reinterpreted
for non-fiction, that reinterpretation lives in this package's own files
(immutable_rules.yaml, protected_scenes.yaml, seeds/WORLD_RULES_SEED.md) —
the generic engine itself was not modified to accommodate this book.

Grounding sources for factual content: universopedroarte.com.br (catalog,
"Living Book Engine v2" branding, sibling-engine ecosystem) and
pedroarte.com.br (author identity, confirmed via redirect to the Amazon
author page). See BOOK_CONSTITUTION.md for the sourcing discipline this
package requires.
